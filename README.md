# ⚖️ Юрист в кармане — lawyer_assistant_v4

Карманный помощник юриста: Конституция РФ, СК РФ, ТК РФ, Закон о защите прав
потребителей РФ, ГК РФ (разделы по профилю практики). Умный поиск, понимающий
вопросы с ошибками, готовые разборы типовых ситуаций, голосовой ввод.
Работает офлайн, без сервера, без сборки — три файла.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Интерфейс (мобильный, одна страница) |
| `app.js` | Поиск (нечёткое сопоставление, Левенштейн, синонимы), сценарии, голос |
| `library.js` | **Библиотека законов** — curated-нормы + полные тексты |
| `update_library.py` | Сборщик: встраивает ПОЛНЫЕ актуальные тексты из `texts/*.txt` |

## Как пользоваться

1. Откройте `index.html` в браузере (Chrome/Edge — для голосового ввода).
2. Введите вопрос своими словами, с ошибками — «как развестись если я на СВО?»,
   «как выселить девушку из своей квартиры?», «не платят зарплату».
3. Сверху — готовый разбор ситуации (если сценарий найден), ниже — нормы.

## Как добавить ПОЛНЫЕ тексты законов (актуальные редакции)

База поставляется с ключевыми нормами по профилю практики. Полные тексты
встраиваются так:

1. Скачайте актуальный текст с **pravo.gov.ru** в формате .txt (UTF-8).
2. Положите в `texts/`. Первая строка — название, статьи — `Статья N. Заголовок`.
3. `python3 update_library.py` — пересоберёт `library.js`.

## Как работает поиск

- Нормализация: ё→е, нижний регистр, ударение на токены.
- Синонимы: «развестись» → расторжение брака; «выгнать» → выселение; «сво» → военнослужащий…
- Нечёткое сопоставление: Левенштейн с отсечкой (1 ошибка в слове ≥4 букв, 2 в слове ≥7).
- Сценарии: 18 готовых разборов (СВО-развод, выселение, возврат товара,
  зарплата, алименты, наследство и др.).

## Ограничения

- Голосовой ввод — Web Speech API (Chrome/Edge, Android), нужен интернет для распознавания.
- Информация справочная, не заменяет консультацию юриста.
- Актуальность текстов проверяйте на pravo.gov.ru.
